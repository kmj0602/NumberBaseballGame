# NumberBaseballGame

파이썬으로 만든 콘솔 숫자야구 미니 프로젝트입니다. 컴퓨터가 만든 정답을 추측하고, 스트라이크와 볼을 참고하여 모든 자리를 맞히는 게임입니다.

> 현재 상태: 핵심 기능 구현을 완료하고 Ubuntu 터미널에서 동작을 확인했습니다. 정답 확인, 중도 종료, 시도 횟수, 입력 기록, 중복 시도 안내도 추가했습니다.

## 1. 개발 목표와 진행 내용

이번 미니 프로젝트는 **하루, 약 6시간 동안 핵심 기능을 구현하고 실제 게임이 정상적으로 동작하는지 확인하는 것**을 목표로 진행했습니다.

- 변수, 문자열, 조건문, 반복문, 기본 함수를 중심으로 구현했습니다.
- 먼저 3자리·4자리 선택, 정답 생성, 입력 검사, 판정, 반복, 승리 처리를 구현했습니다.
- 4자리 게임에서는 정답을 맞히는 데 시간이 걸려, 필요할 때 정답을 확인하는 `answer` 명령을 추가했습니다.
- 진행 상황을 확인하도록 시도 횟수와 입력 기록을 표시합니다.
- 중도 종료와 이전 입력을 다시 시도했을 때의 안내를 추가했습니다.
- 현재 기능 개발은 마무리했으며, 추후 시간이 된다면 히든 룰을 추가하여 개성 있는 게임으로 발전시킬 계획입니다.

| 사용할 운영체제 | Windows, macOS, Linux에서 실행할 수 있도록 표준 라이브러리로 구현 |

## 3. 파일 구성

파이썬 파일 3개와 설명서 1개를 같은 폴더에 둡니다.

| 파일 | 역할 |
| --- | --- |
| `main.py` | 시작 안내, 자리 수 선택, 명령어 처리, 입력 반복, 결과 출력, 횟수·기록 관리, 종료 |
| `game.py` | 중복 없는 무작위 정답 생성, 스트라이크·볼 판정 |
| `validation.py` | 자리 수 선택 확인, 추측 길이·허용 문자·중복 검사 |
| `README.md` | 게임 규칙, 사용 방법, 실행 방법, 배포 안내 |

## 4. 핵심 게임 규칙

| 항목 | 규칙 |
| --- | --- |
| 자리 수 | 게임 시작 시 3자리 또는 4자리 선택 |
| 사용 숫자 | `0`부터 `9`까지 총 10개 |
| 첫 자리의 0 | 허용. `012`, `0123`도 유효 |
| 숫자 중복 | 정답과 추측 입력 모두 금지 |
| 입력 길이 | 선택한 자리 수와 정확하게 일치 |
| 스트라이크 | 숫자와 위치가 모두 일치 |
| 볼 | 숫자는 같지만 위치가 다름 |
| 아웃 | 스트라이크와 볼이 모두 0 |
| 승리 | 3자리에서는 3스트라이크, 4자리에서는 4스트라이크 |
| 시도 제한 | 현재는 최대 시도 횟수 제한 없음 |

정답과 추측은 정수가 아닌 **순서가 있는 숫자 문자열**로 처리합니다. `012`와 `12`는 서로 다른 입력이며, 첫 자리의 `0`을 유지합니다. 한 숫자를 스트라이크와 볼로 동시에 계산하지 않습니다. 정답은 한 게임 동안 바뀌지 않습니다.

## 5. 명령어

| 명령어 | 사용 가능한 시점 | 동작 |
| --- | --- | --- |
| `answer` | 추측 입력 단계 | 정답을 표시하고 다음 입력을 기다림 |
| `quit` | 자리 수 선택 및 추측 입력 단계 | 프로그램 종료 |

- 명령어는 소문자로 정확하게 입력하고 Enter를 누릅니다.
- `answer`를 입력해도 자동으로 승리하거나 게임이 종료되지 않습니다.
- 정답은 시작할 때 자동으로 공개하지 않으며, `answer` 요청 시 표시합니다.
- 명령어는 숫자 입력 검사보다 먼저 처리합니다.
- 현재는 대문자 명령어와 명령어 앞뒤 공백을 자동으로 변환하지 않습니다.

## 6. 시도 횟수와 입력 기록

시도 횟수는 0에서 시작하고, 규칙에 맞는 숫자를 입력할 때마다 1씩 증가합니다. 횟수에 따라 승리 문구를 다르게 출력하지 않습니다.

| 입력 상황 | 시도 횟수 | 입력 기록 |
| --- | --- | --- |
| 유효한 숫자 입력 | 1회 증가 | 추가 |
| 정답을 맞힌 입력 | 1회 증가 | 추가 |
| 이전과 같은 유효한 숫자 입력 | 1회 증가 | 추가 |
| 길이 오류, 문자·공백·기호 포함, 숫자 중복 | 증가하지 않음 | 추가하지 않음 |
| `answer` 또는 `quit` | 증가하지 않음 | 추가하지 않음 |

유효한 숫자 입력을 할 때마다 현재 횟수와 판정 결과를 출력하고, 전체 입력 기록을 보여줍니다.

```text
------------ 입력 결과 기록 ------------
1회 | 0132 | [결과] 2 스트라이크 2 볼
2회 | 3210 | [결과] 0 스트라이크 4 볼
3회 | 0123 | [결과] 4 스트라이크 0 볼
```

위 기록은 정답이 `0123`인 경우의 예시입니다. 기록은 게임 실행 중에만 보관하며, 별도 파일로 저장하지 않습니다.

### 중복 시도 안내

이전에 입력한 숫자 문자열을 다시 입력하면 `[경고] 이전에 입력한 숫자`를 표시합니다. 안내 후에도 정상적으로 판정하고 횟수와 기록에 포함합니다.

**한 입력 안의 숫자 중복**과 **이전 입력을 다시 시도하는 것**은 다릅니다.

- `334`처럼 한 입력 안에서 숫자가 중복되면 입력 오류입니다.
- 유효한 `012`를 다시 입력하는 것은 허용하며, 중복 시도 안내만 표시합니다.

## 7. 입력 확인 예시

추측에는 문자 `0`~`9`만 허용합니다. 문자, 공백, 기호가 포함되면 오류를 안내하고 다시 입력받습니다.

| 자리 수 | 입력 | 결과 |
| --- | --- | --- |
| 3자리 | `012` | 정상 |
| 3자리 | `334` | 오류: 숫자 중복 |
| 3자리 | `12` | 오류: 길이 부족 |
| 3자리 | `0123` | 오류: 길이 초과 |
| 3자리 | `0a2` | 오류: 허용하지 않는 문자 |
| 3자리 | `0 2` | 오류: 공백 포함 |
| 4자리 | `0123` | 정상 |
| 4자리 | `0122` | 오류: 숫자 중복 |

## 9. 게임 진행 순서

1. 시작 안내를 확인하고 3자리 또는 4자리를 선택합니다. 이 단계에서 `quit`으로 종료할 수 있습니다.
2. 컴퓨터가 중복 없는 정답을 생성합니다.
3. 추측 또는 명령어를 입력합니다.
4. `answer`이면 정답을 표시하고 3번으로 돌아갑니다. `quit`이면 종료합니다.
5. 숫자 입력을 검사합니다. 오류가 있으면 안내하고 3번으로 돌아갑니다.
6. 이전과 같은 입력이면 중복 시도를 안내합니다.
7. 시도 횟수를 증가시키고 스트라이크·볼을 판정합니다.
8. 현재 횟수와 결과를 표시하고, 기록에 추가한 뒤 전체 기록을 출력합니다.
9. 정답이면 승리를 안내하고 종료합니다. 정답이 아니면 3번으로 돌아갑니다.

## 10. 다운로드와 실행 방법

**Python 3가 설치된 컴퓨터에서 `main.py`, `game.py`, `validation.py`를 같은 폴더에 두고 `main.py`를 실행하면 됩니다.** `game.py`와 `validation.py`는 main.py가 자동으로 불러오므로 따로 실행하지 않습니다.

### 1단계: 파일 준비

1. GitHub 저장소에서 ZIP 파일을 내려받거나 공유받은 프로젝트 파일을 준비합니다.
2. ZIP 파일이라면 압축을 풉니다. 압축된 상태에서는 실행하지 않습니다.
3. 세 파이썬 파일이 같은 폴더에 있는지 확인합니다. 폴더의 이름과 저장 위치는 자유롭게 정해도 됩니다.
4. Python 3가 없다면 [Python 공식 사이트](https://www.python.org/downloads/)에서 설치합니다.

README.md는 사용 설명서이며 게임 실행에 필수인 파일은 아닙니다.

### 2단계: main.py 실행

#### Windows

세 파이썬 파일이 있는 폴더에서 PowerShell 또는 명령 프롬프트를 열고 실행합니다.

```powershell
python main.py
```

설치 환경에서 `python` 대신 `py` 명령을 사용한다면 다음처럼 실행합니다.

```powershell
py -3 main.py
```

#### macOS / Linux

세 파이썬 파일이 있는 폴더에서 터미널을 열고 실행합니다.

```bash
python3 main.py
```

터미널이 다른 위치에서 열렸다면 `cd "프로젝트 폴더의 실제 경로"`로 이동한 뒤 실행하세요. 이 문구의 경로는 본인이 저장한 폴더 경로로 바꿔야 합니다.

#### 개발 도구에서 실행

VS Code, PyCharm 등에서도 Python 3 실행 환경을 선택하고 `main.py`를 실행할 수 있습니다. 실행 화면에서 키보드 입력이 가능해야 합니다. 실행 대상은 `game.py`나 `validation.py`가 아닌 `main.py`입니다.

#### 파일을 더블클릭해도 되나요?

`.py` 파일이 Python과 연결된 환경에서는 더블클릭으로 실행될 수도 있습니다. 다만 설정에 따라 편집기가 열리거나 게임 종료와 함께 창이 닫힐 수 있으므로, 처음 실행할 때는 터미널 명령을 사용하는 방법을 권장합니다.

### 3단계: 게임 시작

1. 시작 안내를 읽고 `3` 또는 `4`를 입력한 뒤 Enter를 누릅니다.
2. 선택한 자리 수에 맞춰 중복 없는 숫자를 입력합니다.
3. 스트라이크와 볼, 입력 기록을 참고하여 다음 숫자를 추측합니다.
4. 정답 확인은 `answer`, 중도 종료는 `quit`을 입력합니다.

다시 플레이하려면 `main.py`를 다시 실행합니다. 입력 기록은 새 게임으로 이어지지 않습니다.

## 11. 실행할 때 문제가 생기는 경우

| 상황 | 확인할 내용 |
| --- | --- |
| `python`, `python3`, `py` 명령을 찾을 수 없음 | Python 3 설치 여부와 명령 경로 설정 확인. 설치 후 터미널을 다시 열기 |
| `main.py` 파일을 찾을 수 없음 | 터미널이 main.py가 있는 폴더에서 열렸는지 확인 |
| `No module named 'game'` 또는 `'validation'` | game.py와 validation.py가 main.py와 같은 폴더에 있는지 확인 |
| 파일을 열었더니 코드만 보임 | 편집기로 열린 상태. 터미널 또는 개발 도구의 실행 기능으로 main.py 실행 |
| 게임 화면에 입력할 수 없음 | 키보드 입력을 지원하는 터미널에서 실행 |

파일 이름은 정확하게 `main.py`, `game.py`, `validation.py`로 유지하세요. `main.py.txt`처럼 뒤에 `.txt`가 남아 있으면 수정해야 합니다.

## 12. README 보기

GitHub 저장소에서 README를 보면 제목과 표가 정리된 형태로 표시됩니다. 마크다운 미리보기를 지원하는 편집기에서도 같은 방식으로 볼 수 있습니다.

일반 메모장에서는 `#`, `|`, 백틱 같은 마크다운 원문이 보이는 것이 정상입니다. 게임 실행을 위해 설명서를 편집하거나 별도의 미리보기 도구를 설치할 필요는 없습니다.

## 13. 공유 방법

프로젝트를 공유할 때는 파이썬 파일 3개와 README.md를 함께 제공합니다. GitHub 저장소 링크를 보내거나 파일을 ZIP으로 압축해 공유할 수 있습니다.

자동 생성되는 `__pycache__` 폴더는 공유하지 않아도 됩니다. 받은 사용자는 파일을 내려받아 압축을 풀고, Python 3 환경에서 main.py를 실행합니다. 저장소 링크를 열기만 하면 브라우저에서 게임이 실행되는 방식은 아닙니다.
