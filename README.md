# NumberBaseballGame

파이썬으로 만든 콘솔 숫자야구 미니 프로젝트입니다. 컴퓨터가 만든 정답을 추측하고, 스트라이크와 볼을 참고하여 모든 자리를 맞히는 게임입니다.

> 현재 상태: 핵심 기능 구현을 완료하고 Ubuntu 터미널에서 동작을 확인했습니다. 정답 확인, 중도 종료, 시도 횟수, 입력 기록, 중복 시도 안내도 추가했습니다.

## 1\. 개발 목표와 진행 내용

이번 미니 프로젝트는 **하루, 약 6시간 동안 핵심 기능을 구현하고 실제 게임이 정상적으로 동작하는지 확인하는 것**을 목표로 진행했습니다.

* 변수, 문자열, 조건문, 반복문, 기본 함수를 중심으로 구현했습니다.
* 먼저 3자리·4자리 선택, 정답 생성, 입력 검사, 판정, 반복, 승리 처리를 구현했습니다.
* 4자리 게임에서는 정답을 맞히는 데 시간이 걸려, 필요할 때 정답을 확인하는 `answer` 명령을 추가했습니다.
* 진행 상황을 확인하도록 시도 횟수와 입력 기록을 표시합니다.
* 중도 종료와 이전 입력을 다시 시도했을 때의 안내를 추가했습니다.
* 현재 기능 개발은 마무리했으며, 추후 시간이 된다면 히든 룰을 추가하여 개성 있는 게임으로 발전시킬 계획입니다.

## 4\. 핵심 게임 규칙

|항목|규칙|
|-|-|
|자리 수|게임 시작 시 3자리 또는 4자리 선택|
|사용 숫자|`0`부터 `9`까지 총 10개|
|첫 자리의 0|허용. `012`, `0123`도 유효|
|숫자 중복|정답과 추측 입력 모두 금지|
|입력 길이|선택한 자리 수와 정확하게 일치|
|스트라이크|숫자와 위치가 모두 일치|
|볼|숫자는 같지만 위치가 다름|
|아웃|스트라이크와 볼이 모두 0|
|승리|3자리에서는 3스트라이크, 4자리에서는 4스트라이크|
|시도 제한|현재는 최대 시도 횟수 제한 없음|

정답과 추측은 정수가 아닌 **순서가 있는 숫자 문자열**로 처리합니다. `012`와 `12`는 서로 다른 입력이며, 첫 자리의 `0`을 유지합니다. 한 숫자를 스트라이크와 볼로 동시에 계산하지 않습니다. 정답은 한 게임 동안 바뀌지 않습니다.

## 5\. 명령어

|명령어|사용 가능한 시점|동작|
|-|-|-|
|`answer`|추측 입력 단계|정답을 표시하고 다음 입력을 기다림|
|`quit`|자리 수 선택 및 추측 입력 단계|프로그램 종료|

* 명령어는 소문자로 정확하게 입력하고 Enter를 누릅니다.
* `answer`를 입력해도 자동으로 승리하거나 게임이 종료되지 않습니다.
* 정답은 시작할 때 자동으로 공개하지 않으며, `answer` 요청 시 표시합니다.
* 명령어는 숫자 입력 검사보다 먼저 처리합니다.
* 현재는 대문자 명령어와 명령어 앞뒤 공백을 자동으로 변환하지 않습니다.

## 6\. 시도 횟수와 입력 기록

시도 횟수는 0에서 시작하고, 규칙에 맞는 숫자를 입력할 때마다 1씩 증가합니다. 횟수에 따라 승리 문구를 다르게 출력하지 않습니다.

|입력 상황|시도 횟수|입력 기록|
|-|-|-|
|유효한 숫자 입력|1회 증가|추가|
|정답을 맞힌 입력|1회 증가|추가|
|이전과 같은 유효한 숫자 입력|1회 증가|추가|
|길이 오류, 문자·공백·기호 포함, 숫자 중복|증가하지 않음|추가하지 않음|
|`answer` 또는 `quit`|증가하지 않음|추가하지 않음|

유효한 숫자 입력을 할 때마다 현재 횟수와 판정 결과를 출력하고, 전체 입력 기록을 보여줍니다.

```text
------------ 입력 결과 기록 ------------
1회 | 0132 | \[결과] 2 스트라이크 2 볼
2회 | 3210 | \[결과] 0 스트라이크 4 볼
3회 | 0123 | \[결과] 4 스트라이크 0 볼
```

위 기록은 정답이 `0123`인 경우의 예시입니다. 기록은 게임 실행 중에만 보관하며, 별도 파일로 저장하지 않습니다.

### 중복 시도 안내

이전에 입력한 숫자 문자열을 다시 입력하면 `\[경고] 이전에 입력한 숫자`를 표시합니다. 안내 후에도 정상적으로 판정하고 횟수와 기록에 포함합니다.

**한 입력 안의 숫자 중복**과 **이전 입력을 다시 시도하는 것**은 다릅니다.

* `334`처럼 한 입력 안에서 숫자가 중복되면 입력 오류입니다.
* 유효한 `012`를 다시 입력하는 것은 허용하며, 중복 시도 안내만 표시합니다.

## 7\. 입력 확인 예시

추측에는 문자 `0`\~`9`만 허용합니다. 문자, 공백, 기호가 포함되면 오류를 안내하고 다시 입력받습니다.

|자리 수|입력|결과|
|-|-|-|
|3자리|`012`|정상|
|3자리|`334`|오류: 숫자 중복|
|3자리|`12`|오류: 길이 부족|
|3자리|`0123`|오류: 길이 초과|
|3자리|`0a2`|오류: 허용하지 않는 문자|
|3자리|`0 2`|오류: 공백 포함|
|4자리|`0123`|정상|
|4자리|`0122`|오류: 숫자 중복|

## 8\. 판정 예시

|입력|결과|

|`0123`|4스트라이크 0볼 → 승리|
|`0132`|2스트라이크 2볼|
|`3210`|0스트라이크 4볼|
|`4567`|아웃|

## 9\. 게임 진행 순서

1. 시작 안내를 확인하고 3자리 또는 4자리를 선택합니다. 이 단계에서 `quit`으로 종료할 수 있습니다.
2. 컴퓨터가 중복 없는 정답을 생성합니다.
3. 추측 또는 명령어를 입력합니다.
4. `answer`이면 정답을 표시하고 3번으로 돌아갑니다. `quit`이면 종료합니다.
5. 숫자 입력을 검사합니다. 오류가 있으면 안내하고 3번으로 돌아갑니다.
6. 이전과 같은 입력이면 중복 시도를 안내합니다.
7. 시도 횟수를 증가시키고 스트라이크·볼을 판정합니다.
8. 현재 횟수와 결과를 표시하고, 기록에 추가한 뒤 전체 기록을 출력합니다.
9. 정답이면 승리를 안내하고 종료합니다. 정답이 아니면 3번으로 돌아갑니다.

## 10\. 실행 방법

Python 3가 설치된 Ubuntu에서 실행합니다. 외부 패키지는 설치하지 않아도 됩니다.

개발 폴더에 저장한 경우:

```bash
cd \~/work/python/mini\_project/NumberBaseballGame
python3 main.py
```

다른 위치에 압축을 푼 경우에는 해당 `NumberBaseballGame` 폴더에서 터미널을 열고 실행합니다.

```bash
python3 main.py
```

`main.py`, `game.py`, `validation.py`는 반드시 같은 폴더에 두세요. 게임 종료 후 다시 플레이하려면 실행 명령을 다시 입력합니다.
